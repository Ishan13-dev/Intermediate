# Ishan13 Websites 🌐

A responsive, multi-page business website built to help small businesses establish and grow their online presence.

## 🚀 Live Demo

**Website:** [Visit Ishan13 Websites](https://intermediate-ochre.vercel.app/)

## 📌 About the Project

Ishan13 Websites is a front-end web development project designed to demonstrate a professional business website.

The website provides a simple and user-friendly interface where visitors can explore website design services, learn about the business, and get in touch directly.

The project focuses on clean UI design, responsive layouts, easy navigation, and practical use of modern front-end technologies.

## ✨ Features

- **Home Page:** Business introduction with a hero section.
- **About Page:** Information about the business and its purpose.
- **Services Page:** Presentation of available services.
- **Contact Page:** Contact details and WhatsApp integration.
- **Responsive Navigation:** Mobile-friendly navigation menu.
- **Modern UI:** Clean layout with Tailwind CSS.
- **WhatsApp Integration:** Direct communication with visitors.
- **Responsive Layout:** Designed to work across different screen sizes.

## ⚙️ How to Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/Ishan13-dev/Intermediate.git
```

**2. Navigate to the project folder**

```bash
cd Intermediate
```

**3. Open the project**

Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code.

## 🌍 Deployment

This project is deployed using **Vercel**.

To deploy your own version:

1. Visit [Vercel](https://vercel.com/).
2. Sign in using GitHub.
3. Import the Intermediate repository.
4. Configure the deployment settings.
5. Click **Deploy**.
